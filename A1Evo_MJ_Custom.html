A1Evo 1-click Audyssey Optimization Tool MJ Custom - PureEQ v7.2.0

Steps

  1. Download and install the free room correction software Room EQ Wizard (v5.40 Beta) in your computer
    • Download link for the latest REW Beta version: here
  2. Set REW's maximum number of measurements to 1000 - 'Preferences' / 'View' / 'Maximum measurements'
  3. Start REW's local API (application programming interface) server - 'Preferences' / 'API' / 'Start server'
  4. Click the 'Upload calibration' button below to browse to the Audyssey calibration file (.ady) generated by the MultEQ Editor (IOS/Android) app
  1. When prompted, download and 'save' the .zip (measurements) on your computer. Make sure the zip file is unblocked: right-click > properties > unblock
  2. Start REW, go to the 'EQ' / 'House Curve', and select a target curve of your choice
  3. ***If you do not select a target curve, MJC will EQ to a gentle downward slope & enable Dynamic EQ***
  4. Open the zip file and select ALL (keyboard shortcut: "CTRL+A" for Windows / "Command+A" for Mac) the files in that folder
  5. Left click on the selection and drag & drop them onto REW. Wait until all measurements are imported and 'Optimize calibration' button is enabled
  6. In REW left column you should be seeing your Audyssey speaker measurements with increasing index numbers sorted in alphabetical order
  7. Keep REW at "SPL & Phase" tab and close all REW child windows during the optimization process for a robust experience
  8. When all is set, click the 'Optimize calibration' button below and sit back and relax. Your home cinema will be 'transformed' within minutes!
